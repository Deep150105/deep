HTB Certified Junior Cybersecurity Associate

HTB Certified Junior Cybersecurity Associate (HTB CJCA) is a highly hands-on certification that assesses the candidates' understanding and competency across both offensive and defensive cybersecurity domains. They are equipped to identify common cybersecurity pitfalls, basic-level exploitation, and recognize potential security gaps. This is the first certification in our lineup, and they can assess and report on security issues in enterprise environments.

JUNIOR CYBERSECURITY ANALYST 50 MODULES 9 VOUCHER

HTB Certified Penetration Testing Specialist

HTB Certified Penetration Testing Specialist (HTB CPTS) is a highly hands-on certification that assesses the candidates' penetration testing skills. Candidates are able to assess basic technical competency in the ethical hacking and penetration testing domains at an intermediate level. They can spot common security issues, effectively exploit them, and compile a comprehensive report.

SECURITY OPERATIONS ANALYST COURSES 28 MODULES 1 VOUCHER

HTB Certified Web Exploitation Specialist

HTB Certified Web Exploitation Specialist (HTB CWES) is a highly hands-on certification that assesses the candidates' web application pentesting and bug bounty hunting skills. Candidates are familiar with major technical competencies in ethical hacking and web penetration testing at an intermediate level. They can assess the risk of web applications, services, or APIs and compose a commercial-grade, actionable report.

WEB PENETRATION TESTER 30 MODULES 0 VOUCHER
